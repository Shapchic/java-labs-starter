# Лабораторная работа 7: Лямбды и Stream API

Условие: [`assignments/lab07-stream-api.md`](../assignments/lab07-stream-api.md).

Из корня репозитория запустите:

```bash
./mvnw -pl lab07 test
```

Windows PowerShell: `.\\mvnw.cmd -pl lab07 test`.

Основной код размещайте в `src/main/java/edu/course/lab07/`, тесты — в `src/test/java/edu/course/lab07/`. В начале каждого Java-файла укажите `package edu.course.lab07;`.

Модуль независим от остальных лабораторных. Если нужны модели из предыдущей работы, перенесите и при необходимости адаптируйте только нужные классы в этот модуль. Начальная успешная сборка не является выполнением задания: создайте реализацию и собственные тесты по условию.
