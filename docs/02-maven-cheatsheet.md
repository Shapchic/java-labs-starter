# Краткая памятка Maven

Maven отвечает за компиляцию, запуск тестов и сборку проекта. Конфигурация уже подготовлена преподавателем.

## Основные команды

```bash
./mvnw test                    # тесты всех модулей
./mvnw -pl lab01 test          # тесты первой лабораторной
./mvnw -pl lab04 test          # тесты четвертой лабораторной
./mvnw clean test              # удалить старую сборку и запустить тесты
./mvnw -pl lab01 package       # собрать модуль первой лабораторной
```

В Windows используйте `.\mvnw.cmd` вместо `./mvnw`.

Все модули `lab01`–`lab08` уже существуют и перечислены в секции `<modules>` корневого `pom.xml`. Команда `-pl labXX` выбирает только один из них. В пустых модулях без тестов успешная сборка проверяет лишь конфигурацию; тесты к заданию студент добавляет сам.

## Основные каталоги

- `src/main/java` — основной код;
- `src/test/java` — тесты;
- `pom.xml` — описание модуля;
- `target` — сгенерированный результат сборки.

## Как читать ошибку

1. Найдите первый `COMPILATION ERROR`, `There are test failures` или `Caused by`.
2. Найдите имя файла и номер строки.
3. Исправьте первую ошибку и запустите команду снова.
4. Не начинайте с последних десятков строк stack trace: они часто являются следствием первой ошибки.

Не изменяйте версии плагинов и зависимостей без задания преподавателя.
