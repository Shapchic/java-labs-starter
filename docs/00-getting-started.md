# Первый запуск проекта

## Что должно быть установлено

- Git;
- JDK 25;
- IntelliJ IDEA, Eclipse или VS Code с поддержкой Java.

Отдельно устанавливать Maven не требуется: проект содержит Maven Wrapper.

## Проверка Java

```bash
java --version
javac --version
```

Обе команды должны показывать совместимую версию. Если терминал и IDE используют разные JDK, установите JDK 25 как Project SDK в настройках IDE.

## Клонирование

```bash
git clone <адрес-личного-репозитория>
cd <каталог-репозитория>
```

## Первый запуск

macOS и Linux:

```bash
./mvnw test
```

Windows PowerShell:

```powershell
.\mvnw.cmd test
```

Первый запуск может занять больше времени: Maven загружает зависимости. Успешный результат заканчивается сообщением `BUILD SUCCESS`.

В исходном шаблоне все тесты проходят. Если первый запуск завершается ошибкой до внесения изменений, не исправляйте учебный код наугад: сначала проверьте версию JDK и сообщите преподавателю.

## Где находится код

```text
lab01/src/main/java/     основной код, включая CourseToolkit.java
lab01/src/test/java/     два исходных теста и тесты студента
lab02/ ... lab07/        пустые стартовые модули для следующих работ
lab08/src/main/java/     каркас для конкурентной обработки
lab01/target/            результат сборки, не добавлять в Git
```

Все восемь модулей доступны сразу. Пока в модуле нет тестов, `BUILD SUCCESS` не подтверждает выполнение задания: добавьте собственные JUnit-тесты по условию работы.

Если вы создали личный репозиторий до появления модулей `lab02`–`lab08`, следуйте [инструкции по обновлению](08-existing-repositories.md). Не открывайте PR в репозиторий преподавателя.

Если сборка не работает, сначала прочитайте первую содержательную ошибку, а затем обратитесь к памятке [«Частые ошибки»](06-common-errors.md).
